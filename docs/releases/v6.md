# Caltemp v6.0.0

Caltemp v6 présente l'application comme un calendrier local moderne pour organiser les journées, les cours, les échéances, les examens et les notes sans dépendre d'un compte en ligne.

## Points clés

- Calendrier local-first : les données utilisateur restent dans le stockage applicatif Tauri, avec une politique de confidentialité simple et explicite.
- Vues de calendrier : navigation par année, mois, semaine et jour pour passer rapidement d'une vision globale au détail d'une journée.
- Import/export ICS : import de fichiers `.ics`, export du calendrier et base prête pour des sources connues plus rapides à configurer.
- Notifications : rappels locaux, toast applicatif et notification native quand l'application est en arrière-plan.
- Dexter : assistant intégré pour créer des événements en langage naturel et aider à organiser les informations, avec clé API optionnelle pour les réponses IA enrichies.
- Personnalisation : thème sombre, fonds Unsplash configurables, sons personnalisés et réglages d'interface.
- Notes intégrées : espace de notes avec pièces jointes, éditeur riche et export Markdown.
- Distribution v6 : version technique `6.0.0`, lockfile npm, audits de dépendances, Dependabot et workflow de sécurité GitHub Actions.

## Sécurité et maintenance

La v6 ajoute une base plus robuste pour les mises à jour :

- `package-lock.json` rend les installations reproductibles et permet `npm audit`.
- Dependabot surveille npm, Cargo et les GitHub Actions.
- Le workflow `Security Audit` exécute `npm ci`, `npm audit --audit-level=moderate`, `npm run lint`, `npm run build`, `cargo check` et `cargo audit`.
- Les versions sont synchronisées entre `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` et `public/version.json`.

## Confidentialité

Caltemp ne collecte pas de données personnelles. Les fonctions connectées comme Unsplash ou l'IA optionnelle ne sont utilisées que lorsqu'elles sont configurées ou déclenchées par l'utilisateur.
